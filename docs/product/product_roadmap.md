# Product Roadmap Overview (Internal)

**Department:** Product
**Version:** 1.0
**Last Updated:** 2026-02-01

## Current Focus (Q1-Q2 2026)

The product team is prioritizing three initiatives: (1) a self-serve onboarding flow to reduce time-to-value for new customers, (2) an analytics dashboard revamp, and (3) SOC 2 Type II certification support for enterprise customers, coordinated closely with the Security team.

## Feature Request Process

Customer-facing feature requests are logged in the Product Intake system by Customer Success. The Product team triages requests biweekly and scores them using a RICE (Reach, Impact, Confidence, Effort) framework.

## Beta Program

Enterprise customers may opt into the Beta Program to access features up to 6 weeks before general availability. Beta features are excluded from the standard SLA.
